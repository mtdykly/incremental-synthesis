# Partition-Based Incremental Synthesis Prototype

本目录用于实现基于设计分区的Yosys增量综合原型，与已有ECO全量综合差异实验分开。

第一版分区策略：

- 以顶层模块`riscv_core`的第一层层次实例作为分区根。
- 分区根模块边界保留。
- 每个分区内部的子模块允许展平。
- 顶层`riscv_core`作为连接各分区的top shell。

当前阶段：

1. 生成展平前的层次化Yosys JSON。
2. 提取顶层第一层实例。
3. 递归计算每个分区内部包含的模块。
4. 识别被多个分区共同使用的模块定义。

后续阶段：

1. 单独综合各分区。
2. 计算接口签名和实现签名。
3. 检测失效分区。
4. 复用未失效分区综合网表。
5. 拼接完整设计并进行等价验证。

## 第二阶段：独立分区综合

当前已支持：

1. 根据 partition manifest 读取全部第一层分区。
2. 分别以每个分区根模块作为综合顶层。
3. 保留分区根模块接口。
4. 展平分区内部所有层次实例。
5. 为每个分区独立生成 frontend、flattened、synth 和门级网表。
6. 检查分区内部层次是否完全展平。
7. 检查综合前后分区接口是否保持一致。

当前暂不支持参数化的第一层分区根实例。

## 第三阶段：顶层 Shell 与分区链接

当前已支持：

1. 将第一层分区根模块转换为 blackbox。
2. 单独综合顶层 riscv_core 的连接逻辑。
3. 检查 blackbox 接口与独立分区接口一致。
4. 读取顶层 shell 和各分区综合网表。
5. 将独立分区重新链接成完整设计。
6. 检查所有顶层分区实例均能解析到真实实现。
7. 分别记录顶层 shell 和链接阶段的运行时间。

## 第四阶段：全量参考综合与形式等价验证

当前已支持：

1. 对完整设计执行全量展平综合。
2. 生成全量综合参考 JSON、RTLIL 和门级网表。
3. 检查全量综合网表中不存在层次化子模块实例。
4. 比较全量综合结果和分区链接结果的顶层接口。
5. 将分区链接网表展平后与全量综合结果进行比较。
6. 对两侧异步触发器执行一致的 async2sync 规范化。
7. 使用 equiv_make、equiv_simple 和 equiv_induct 进行顶层等价证明。
8. 使用 equiv_status -assert 保证不存在未证明的 equivalence cell。

本阶段证明分区独立综合并重新链接的结果，在顶层功能上与完整全量综合结果等价。

## 第五阶段：分区签名与缓存失效判断

当前已支持：

1. 从展平前的层次化 Yosys JSON 计算分区签名。
2. 为每个分区分别计算接口签名和实现签名。
3. 实现签名包含分区内部模块、根实例参数、Yosys 版本和综合流程。
4. Base 的独立分区综合网表作为缓存结果。
5. New 版本仅执行前端处理和签名计算。
6. 自动判断可复用分区和需要重新综合的分区。
7. 自动判断顶层 shell 是否需要重新生成。
8. 输出每个分区失效或复用的具体原因。

当前使用保守结构签名。签名相同且缓存存在时允许复用；
签名不同则重新综合，不尝试证明两个不同 IR 是否功能等价。
